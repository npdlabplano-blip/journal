# Progress Photos

Taken every 2 weeks alongside body measurements. Same lighting, same poses, same location.

## How to Take Progress Photos
- **When:** Every 2 weeks, morning, same time as measurements
- **Where:** Same spot with consistent lighting (bathroom mirror or a blank wall)
- **What to wear:** Form-fitting clothes or workout gear — same outfit each time
- **Poses:** Take 3 photos each session:
  1. Front facing
  2. Side profile (left)
  3. Back facing
- **Storage:** Save photos to `nutrition/photos/` with naming format: `YYYY-MM-DD-front.jpg`, `YYYY-MM-DD-side.jpg`, `YYYY-MM-DD-back.jpg`

## Notes
- You won't see changes in photos for the first 3–4 weeks. That's normal. Keep taking them.
- Side-by-side comparisons are incredibly motivating once changes start showing.
- Photos catch changes the scale misses — posture, muscle definition, how clothes fit.
